# violet-s-Space-Marine-1-mod-tools
Some tools I have made for Space Marine One modding alongside a couple original tools from santos and Copernicus aka cope With some improvements


# tools that are Included

## smbod_attrib_converter

Which allows for converting both bod and attr_pc files All in one program 

## sm1 dcm import export 

Which is a blender importer and exporter for sm1 DCM models That also includes a custom shader created by me and it also will auto import the textures set up the shader automatically as well

## pbr_to_spc 

Allows you to convert Standard PBR textures to SM1 textures 

# Texture formats

## _dif 
Self explanatory

## _nrm
Self explanatory

## _spc
Specular texture that is used kind of like Highlights for the meshes

## _ref
Reflection map from what I can tell is only really used for gold parts of armor

## _lp

The most standard version is like this
RED = Glossiness I think?
GREEN = Emissive
BLUE = Mask for _ref

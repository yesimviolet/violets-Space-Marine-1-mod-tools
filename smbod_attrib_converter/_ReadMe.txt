2. Usage:

Extract the attr_pc files you'd like to convert. Put them in a folder of your choice and start the tool. By default it will convert the files from XML to BAF from the current folder.
Here are the available parameters:

-f					// switch single file mode on (-i and -o specify a file in this mode)
-x					// convert to XML from BAF
-i <input_path> 	// set input path
-o <output_path> 	// set output path (if single file mode is switched on and you don't specify -o, it will just change the extension of the file)
